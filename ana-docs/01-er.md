## 实体明细 (46 张表)

### 产品体系 (10 表)

| 实体 | 表名 | 主键 | 描述 |
|------|------|------|------|
| **Brand** | brands | id | 品牌，含 logo/website/status |
| **Product** | products | id | 产品主表，含 sku/price/status/quantity |
| ProductDescription | product_descriptions | (product_id, locale) | 多语言描述（名称/详情/元数据） |
| ProductSku | product_skus | id | SKU 库存单元（多规格） |
| ProductImage | product_images | id | 产品图片，支持排序 |
| **Category** | categories | id | 分类，含 slug/image |
| CategoryDescription | category_descriptions | (category_id, locale) | 分类多语言名称 |
| CategoryPath | category_paths | (category_id, path_id) | 分类树路径 |
| ProductCategory | product_categories | (product_id, category_id) | 产品-分类关联 |
| ProductRelation | product_relations | (product_id, related_id) | 关联产品 |

## 关系类型说明

| 关系 | 说明 | 示例 |
|------|------|------|
| belongs_to | 外键引用 | Product.brand_id → Brand.id |
| has_many | 一对多 | Brand → Products |
| many_to_many | 多对多 | Product ↔ Category (通过 product_categories) |
| polymorphic | 多态关联 | Notification.notifiable_id + notifiable_type |
| locale | 多语言描述 | Product → ProductDescription |
| tree | 自引用树 | Category → CategoryPath |
